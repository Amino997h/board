# AI Interactive Whiteboard Explainer 🎨👨‍🏫

تطبيق ويب ذكي يحول أي موضوع أو مسألة إلى **شرح تفاعلي سينمائي على سبورة بيضاء لانهائية**، يجمع بين الرسم الحي للأشكال والمخططات، إدراج الصور التوضيحية من الإنترنت، والشرح الصوتي البشري المتزامن لحظة بلحظة.

---

## ✨ المميزات الرئيسية
1. **السبورة اللانهائية (Infinite Canvas & Smooth Camera):**
   - كاميرا متحركة ذكية تتبع شرح الأستاذ خطوة بخطوة وتنتقل إلى مساحات بيضاء جديدة بسلاسة مع الحفاظ على الرسومات السابقة.
   - إمكانية التنقل والتصفح الحر بالسحب بالفأرة (Drag & Pan) مع ميزة العودة التلقائية للوضع المباشر (Auto-Snap to Live Focus) فور إفلات الفأرة.
2. **أنيميشن رسم وكتابة واقعي:**
   - رسم أضلاع المربعات والمخططات والأسهم خطاً بخط.
   - كتابة النصوص التوضيحية حرفاً بحرف (Typewriter animation) مع نظام ذكي لمنع خروج النص خارج الصندوق (Word-wrapping).
3. **توليد صوتي بشري طبيعي متواصل:**
   - نطق عربي وإنجليزي انسيابي عالي الجودة عبر تقنية `edge-tts` الصوتية.
4. **جلب الصور التلقائي من الإنترنت:**
   - جلب وتنزيل صور توضيحية شفافة وكرتونية تناسب نمط السبورة لكل مكون يتم شرحه.
5. **مرونة كاملة في إعدادات الـ API:**
   - إمكانية التبديل بين أي مزود (OpenAI، أو سيرفر محلي مثل Ollama أو LM-Studio أو ChatGPT Bridge).
   - نافذة إعدادات مدمجة لتعديل الروابط والمفاتيح في أي لحظة.

---

## 🚀 التثبيت والتشغيل

### المتطلبات:
- Python 3.8+
- تثبيت الحزم المطلوبة:
  ```bash
  pip install fastapi uvicorn edge-tts requests pydantic pillow json-repair
  ```

### التشغيل:
```bash
python main.py
```
ثم افتح المتصفح على:
`http://127.0.0.1:8000`
